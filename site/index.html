PLATFORM 1 · HEATWhat explains the heat

Sample CPU temperature, power, top CPU activity, charging, episodes and session receipts. Process percentages are of one core and do not prove heat causation. Only CPU die sensors use temperature reference bands; these are not hardware safety limits. Thermal pressure is macOS's separate assessment.

PLATFORM 2 · CPUWhat is using the CPU

Whole-system load: 100% means all cores. Per-process CPU: 100% means one core, so multithreaded apps can exceed 100%. LOW, MOD and HIGH describe utilization, not heat. The top five processes are smoothed. Unmeasured work is estimated from all sampled processes, so the rows do not add up to the headline.

PLATFORM 3 · RAMWhere the memory went

Used and installed memory, OS pressure and app footprints. Usage alone is not memory strain. App, wired and compressed count as used; cached memory is reclaimable and free memory is unused. App shares describe installed RAM, not heat; app footprints do not add up to total memory used.

Simulated readings at four times speed. HOLD pauses the sample clock, including recordings. Nothing here reads your Mac or saves a session after reload.

In the app, Control + Option + T opens the board from any app. Settings offers T, H or OFF. This webpage does not register a global shortcut. Pressure remains a separate OS assessment, not a temperature threshold.

TICKET MACHINE

  1. Install with Homebrew (or download the zip and drag Thermals to Applications)

    brew install --cask radkode/thermals/thermals

  2. Open Thermals. It lives in the menu bar, with no Dock icon. Open Settings (⌘,) to choose the menu bar reading, °C or °F, sampling interval, heat alerts and launch at login.

  3. Click the reading when the Mac feels hot. ⌘1, ⌘2 and ⌘3 switch between the HEAT, CPU and RAM boards.

Runs on

Apple Silicon Macs with macOS 14 or later. Intel Macs aren't supported yet.

Readings

Temperatures come from the same Apple Silicon sensor source Stats and iStat Menus use. A reading it can't get shows as unavailable, never a guess.

Distribution

Signed with a Developer ID and notarized by Apple, outside the Mac App Store, since the sandbox can't read sensor temperatures.

Source

Free and open source under the MIT license. Read the code, open an issue or send a pull request. Report security problems privately, never in a public issue.
