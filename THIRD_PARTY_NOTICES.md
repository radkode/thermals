The app includes `LICENSE`, `Sparkle-LICENSE.txt` and `OFL.txt` in `Contents/Resources`. `scripts/check-licenses.sh <Thermals.app>` compares those resources with the source notices. Native CI and release packaging run this check.

When updating Sparkle in `project.yml`, replace `Thermals/Notices/Sparkle-LICENSE.txt` with the complete license from that exact upstream release, including its bundled-component terms. Retain the font notices when updating or converting the fonts. The app icon is generated by this repository's `AppIconTests`; the maintainer reports no other known copied code or assets.
